# SheetJS 설치 경로

2026-11-04 · 출처: npm 보안 권고 API, [SheetJS 설치 문서](https://docs.sheetjs.com/docs/getting-started/installation/nodejs/)

## 결정

npm의 `xlsx`가 아니라 SheetJS 공식 배포 주소의 `0.20.3`을 쓴다.

```
https://cdn.sheetjs.com/xlsx-0.20.3/xlsx-0.20.3.tgz
```

## 이유

npm 레지스트리의 최신판은 `0.18.5`이고 높음 등급 권고가 2건 있다. 수정판은 npm에 올라와 있지 않다.

| 권고 | 영향 받는 버전 |
| --- | --- |
| Prototype Pollution in sheetJS | 0.19.3 미만 |
| SheetJS Regular Expression Denial of Service | 0.20.2 미만 |

이 라이브러리는 사용자가 올린 파일을 파싱하므로 공격 입력이 그대로 들어온다.

## 비용

- 설치가 CDN에 의존한다. CDN이 내려가면 새 설치와 CI가 실패할 수 있다. `package-lock.json`의 무결성 값으로 내용 변조는 잡지만 가용성은 막지 못한다.
- `npm audit`과 자동 업데이트가 이 패키지의 새 버전을 알려 주지 않는다. 직접 확인해야 한다.

## 추가 방어

- 파일 크기 5MB, 2만 행 제한. `sheetRows`로 읽을 행도 제한한다.
- Worker 안에서 파싱하고 결과는 단순 값으로만 받는다.
- 저장 전 서버가 값을 다시 검증한다.
